\# NeoNet - Smart Water Management System

\*\*IoTrix 2.0 Semi-Final Submission | Track A: Embedded IoT System\*\*



NeoNet is an edge-controlled water distribution and telemetry system featuring differential flow calculation for instantaneous leak localization and automated dual-valve shutoff triggered by continuous water quality monitoring.



\## Repository Contents

\* \*\*`technical\_progress\_sheet/`\*\*: Contains the mandatory 1-page PDF progress report.

\* \*\*`system\_architecture\_diagram/`\*\*: Contains the visual architecture and data flow of the system.

\* \*\*`hardware\_evidence/`\*\*: Photos of the physical hardware setup, ESP32 wiring, and solenoid valves.

\* \*\*`testing\_validation/`\*\*: Screenshots of the Flutter dashboard receiving live data and videos.

\* \*\*`esp32\_firmware/`\*\*: C++ Arduino code for the ESP32 NodeMCU.

\* \*\*`flutter\_app/`\*\*: Dart source code for the cross-platform mobile dashboard.
